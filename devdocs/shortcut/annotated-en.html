14 actions · receives a { filename, cmd } dictionary from the share sheet, guarantees the image is present on disk, then runs the command in a-Shell Mini.

The problem this shortcut solves

a-Shell can only read files that live in its own File Provider Storage sandbox. An image that exists only in the iOS photo library is invisible to it.

So the shortcut first checks whether the requested file is already on disk. If it is, it does nothing. If it isn't, it pulls the image from Photos and writes it there — and in both cases it then runs the command against a path that is guaranteed to exist.

7 · core logic

Is the opened file the one we asked for?

Two equality checks combined with AND:

trimmedFilename == Inputfile.Name
TrimmedExr == Inputfile.File Extension

Why this works: if the file exists, those properties describe the file itself and both tests pass. If it's missing, they describe the parent folder instead — whose name is File Provider Storage and whose extension is empty — so both tests fail.

No hardcoded constants: the test fixes itself if the target folder ever changes.

The true branch is empty and that's deliberate — the file is present, there's nothing to do.

9

Search the photo library

Name filter — matches on trimmedFilename, without the extension.

Date filter — a deliberate cutoff, for performance: it prunes the PhotoKit index instead of scanning the whole library. The predicate is pushed down to the system, which is where the speedup comes from.

Sorting — by last modified date, newest first, then limited to 1. Without a sort, two same-named photos would return an arbitrary result; here you deterministically get the most recently edited version.

13

Assemble the command line

CmdText + space + path + filename, in a single action.

Spaces in the path are escaped with \. Quotes don't work here: a-Shell treats them literally, and they would also suppress ~ expansion.

Known limitation: filename itself isn't escaped. A space or apostrophe in the name would break the command — harmless in practice, since photo library names look like IMG_1234.HEIC.

14 · output

Execution

Two commands in sequence. The cd sets the working directory — useful for any files the script writes out — then CMDfinal runs.

The path appears in both without conflict: ~File\ Provider\ Storage/ is an alias that always resolves to an absolute location, so the cd doesn't affect how the argument resolves.

Logic in brief

Invariant guaranteed at End If: the file named filename exists in File Provider Storage.

How it's established: try to open it, verify that what came back really carries the requested name and extension, and if it doesn't, fetch the image from Photos and write it to that location.

The key trick: a failed open isn't detected by an empty value — iOS returns the parent folder's properties instead. That's why the test compares name + extension rather than checking for null.
